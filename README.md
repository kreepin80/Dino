# DINO: Wild Island v13

v13 — визуальный апгрейд поверх стабильной v12.

## Что нового
- локальные 3D mesh-модели динозавров: T-Rex, Velociraptor, Stegosaurus, Triceratops;
- модели хранятся в `models/*.json` и не зависят от CDN;
- рядом с JSON лежат OBJ/MTL-исходники тех же моделей;
- полигональный рендер с освещением по граням и мягкой анимацией движения;
- сохранены исправления v12: атака через стены блокируется, динозавры не проходят здания, мини-карта показывает животных только при обнаружении/прямой видимости;
- сохранены туман войны, день/ночь, квесты, здания и скрытый respawn.

## Установка
Загрузить содержимое папки `DINO_Wild_Island_v13` в репозиторий GitHub Pages. Внешние CDN не используются.

## Лицензии
Встроенные mesh-модели в этой версии являются оригинальными низкополигональными моделями проекта, созданными для DINO: Wild Island. Quaternius Animated Dinosaur Pack изучался как референс для будущего импорта настоящих rigged assets; сам Quaternius pack распространяется по CC0 и содержит T-Rex, Velociraptor, Triceratops, Stegosaurus, Apatosaurus и Parasaurolophus с анимациями.
