# DINO: Wild Island — FINAL

Safari/GitHub Pages build.

## Исправления
- Исправлена критическая синтаксическая ошибка в AI, из-за которой JavaScript останавливался и кнопка «НАЧАТЬ» не работала.
- Окна интерфейса подняты выше слоя управления.
- Кнопка «НАЧАТЬ» и кнопки квестов работают через Pointer Events.
- Виртуальный джойстик полностью невидим. Касание в любой точке левой половины экрана задаёт плавающую точку управления.
- Добавлены коллизии для окружения.
- Хищники преследуют, обходят препятствия и атакуют; травоядные убегают.
- Добавлены смена дня/ночи, погода, туман/дождь, костёр лагеря.
- Добавлено локальное сохранение прогресса.
- Добавлена дополнительная сюжетная цель R-7.
- Сохранены прокачка, квесты, ресурсы, база, мини-карта и лор.

## GitHub Pages
Загрузи содержимое архива в репозиторий → Settings → Pages → Deploy from branch → main → root.

## Управление iPhone
Левая половина экрана — движение без видимого джойстика. Правая часть — атака, рывок и лечение.
